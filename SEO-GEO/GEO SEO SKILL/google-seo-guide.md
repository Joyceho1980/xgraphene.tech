# 谷歌SEO优化完全指南

> 来源：小红书 · 拓海SEO外 · 合集共26集
> 标签：#谷歌seo #跨境电商运营 #外贸独立站 #代运营

## 适用场景

- 当用户需要了解谷歌SEO基础框架时
- 当网站需要做SEO诊断（检查GSC、TTFB、Core Web Vitals等）
- 当需要制定关键词策略/内容集群时
- 当需要落地EEAT（经验/专业/权威/可信）时
- 当需要适配AI搜索（GEO+SEO双引擎）时

## 一、核心变化：三大转向

### 1️⃣ EEAT：从加分项到硬性门槛
EEAT = **经验（Experience）、专业（Expertise）、权威（Authoritativeness）、可信（Trustworthiness）**

- 低 EEAT 页面即便关键词匹配度再高，也会被压到后排
- 完善"关于我们"页面，放真实团队照片和地址
- 内容中用具体案例代替空洞描述
- 展示客户评价和媒体引用等第三方认可

### 2️⃣ AI搜索：改写流量分配规则
- 谷歌搜索结果顶部推出 **AI概览**，直接生成答案并标注来源，排在所有自然链接之前
- **信息类查询** → 瞄准被AI概览引用
- **商业类查询** → 仍争取排进第一页
- 核心答案放在章节前50-70个词内，用标题标记常见问题

### 3️⃣ 用户体验指标：权重持续提升
| 指标 | 目标值 | 影响 |
|-----|--------|------|
| LCP（最大内容绘制） | ≤ 2.5秒 | 速度每提升0.1秒，排名可上升1-2位 |
| INP（交互响应） | ≤ 200毫秒 | 仅42%的移动端网站达标 |
| CLS（布局偏移） | ≤ 0.1 | 偏移越大用户跳出率越高 |

## 二、技术SEO：让谷歌找得到你

### 可抓取与可索引
1. 用 **Google Search Console** 验证网站所有权
2. 提交XML站点地图（Sitemap）
3. **内容没被收录，一切优化无从谈起**

### Core Web Vitals 优化
- 启用压缩和CDN
- 图片用 WebP/AVIF 格式并延迟加载
- 裁剪未使用的CSS和JS
- 减少TTFB（首字节时间 < 1.5s）

---

## 三、内容策略：从关键词到主题权威

### 1️⃣ 三级关键词库
| 层级 | 数量 | 覆盖目标 |
|:----:|:----:|---------|
| **核心词** | 1-3个 | 覆盖行业主词 |
| **扩展词** | 20-50个 | 覆盖产品功能 |
| **长尾词** | 100+个 | 覆盖场景化问题 |

> 📌 避开"购买XX"这类竞争激烈的商业词

### 2️⃣ 主题集群架构（Topic Cluster）
```
支柱页面（3000-5000字）
  瞄准核心词
  ↓ 内链双向连接  ↑
集群页面（1000-2000字）
  瞄准长尾词
```
- 内链双向连接，形成网状结构
- 向谷歌传递："这个领域我很专业"的信号

### 3️⃣ 匹配搜索意图
- 写作前先观察搜索结果前五名的格式
- 案例：用户搜"如何加速WordPress" → 要的是分步指南，而不是产品页
- **SEO不是写你想写的，而是写用户想要的**

### 4️⃣ EEAT落地
- ❌ "这个功能很好用"
- ✅ "我们帮客户用了这个功能，结果如何..."
- **用数据和案例替代空洞形容词**

---

## 四、外链建设：质量远大于数量

- 谷歌会忽略低质外链
- **一篇权威网站的自然引用** > **几十条垃圾链接**
- 通过数字PR和创造有用内容来获取链接，而非制造链接

---

## 五、数据驱动

- 使用 **Google Search Console** 查看抓取问题、索引状态、搜索表现
- 使用 **GA4（Google Analytics 4）** 分析用户行为
- 使用 **PageSpeed Insights** 检测 Core Web Vitals
- 定期审计、跟踪排名，确保每次优化都有据可查

---

| 层面 | 目标 |
