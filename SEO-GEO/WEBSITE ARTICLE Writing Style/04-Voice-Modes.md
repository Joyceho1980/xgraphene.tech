# 04 — Voice Modes

> XIHE website articles operate in one of three voice modes.
> These modes correspond to the founder voice system, adapted for website pages.

Each page should have one primary mode. Do not blend all three modes into one page unless there is a very strong reason.

---

## Mode 1: System Thinker

**Purpose:** Establish the height of the thinking. Page feels like a macro-level observation.

**Best for:**
- Category-level pages (Energy, Recovery, Inflammation)
- Overview / umbrella pages
- Philosophy pages
- Pages that define XIHE's worldview

**Voice traits:**
- Calm, low-emotion
- Contrast-driven
- Short structural statements
- Final insight is a framework, not a slogan

**Typical structure:**
1. Visible trend or phenomenon
2. Counterintuitive turn
3. System-level explanation
4. Short concluding judgment

**Example cues:**
- "But the system behaves differently."
- "These are not the same class of problems."
- "Two different clocks are running."

**Example sentence shape:**
> The modern approach treats fatigue as a symptom to be managed. But fatigue is often a signal of incomplete system recovery. These are different problems requiring different responses.

---

## Mode 2: Science Observer

**Purpose:** Build credibility through careful, precise biological explanation.

**Best for:**
- Mechanism pages (ATP, Mitochondria, Microcirculation)
- Evidence-backed pages
- Deep-dive articles
- Translation of research

**Voice traits:**
- Restrained
- Precise
- Careful with claims
- Mechanism-aware
- Interpretation without overstatement

**Required language pattern:**
| Prefer | Avoid |
|---|---|
| Emerging | We proved |
| Observed | Our data shows |
| Associated with | This confirms |
| Suggests | This demonstrates clinical efficacy |
| Reported in preclinical literature | This is effective for |

**Typical structure:**
1. Biological problem
2. Mechanism context
3. Literature framing
4. Careful interpretation
5. Open question

**Example cues:**
- "It is still an emerging area of study."
- "The question is not whether, but where."
- "What is not yet fully understood..."

**Example sentence shape:**
> In preclinical literature, macrophage polarization is increasingly discussed as a key regulatory axis. M1 and M2 states are not fixed endpoints, but dynamic transitions.

---

## Mode 3: Founder Philosopher

**Purpose:** Create memory, brand personality, and a distinct philosophy layer.

**Best for:**
- About pages (Mission, Philosophy)
- Brand content
- Closing sections of key pages
- Pages about XIHE's approach

**Voice traits:**
- Short sentences
- Pause-driven rhythm
- Conceptual restraint
- One concept word can stand alone
- Does not over-explain itself

**Typical structure:**
1. One visible phenomenon
2. One counterintuitive observation
3. One concept word or short insight
4. One closing line

**Example cues:**
- "Not emptiness. Not absence."
- "Between signals, meaning forms."
- "This is not delay. It is design."

**Example sentence shape:**
> The market rewards speed. But biology rewards patience. 留白. (Or: Space. Not emptiness. A place where recovery can complete.)

---

## Mode Comparison

| Aspect | System Thinker | Science Observer | Founder Philosopher |
|---|---|---|---|
| Function | Exposure | Credibility | Memory |
| Style | Sharp, macro, structured | Careful, precise, technical | Poetic, minimal, reflective |
| Risk | Too abstract | Too cautious | Too vague |
| Best page type | Overview / umbrella | Deep-dive / mechanism | Philosophy / about |
| Sentence length | Medium | Medium-long | Short |
| Emotional register | Calm | Neutral | Warm |

## Assigning Mode Per Page

| Page Topic | Recommended Mode |
|---|---|
| "Returning technology to the rhythm of life" (Homepage Hero) | Founder Philosopher |
| "Three Truths" (Foundational Science) | System Thinker + Science Observer (blend, two sections) |
| "About XIHE / IKKEM Alliance" | Founder Philosopher |
| "Why Am I Always Tired" | System Thinker |
| "What Is ATP and Why It Matters" | Science Observer |
| "When Sleep Ends but Recovery Doesn't" | System Thinker |
| "Recovery Environment" | System Thinker + Founder Philosopher |
| "What Is Microcirculation" | Science Observer |
| "Engineering for Life" (Brand Section) | Founder Philosopher |
| "Applications / Partnership" | System Thinker |

## Rule

When drafting a page:
1. First decide the mode
2. Then decide the visual direction
3. Then write the content
