# XIHE GEO — AI搜索用户旅程地图

> 来源：机器人分析（2026-06-23）
> 核心洞察：康复机构采购决策者不会搜"石墨烯"，他们搜的是问题。
> GEO策略目标：在用户旅程的每一层，让AI引用XIHE的内容。

---

## 核心原则

康复机构CEO、Clinical Director、采购经理不会搜：
```
What is graphene?
```

他们会搜：
```
How can I improve patient recovery outcomes?
```

**石墨烯不是入口词。入口词是：**
Recovery / Sleep / Fatigue / Pain / Circulation / Rehabilitation / Post-operative recovery

**石墨烯是决策词（中后段）：**
Graphene / Emissivity / Radiant Efficiency / Medical-grade FIR

## 核心洞察总结

1. **"石墨烯远红外"不是入口词** — 入口词是 Recovery / Sleep / Fatigue / Pain / Circulation
2. **Root Cause Hub（线粒体→细胞能量→Graphene FIR）是整个漏斗的顶部** — 价值高于任何单一页面
3. **第三层（定义权）是XIHE的主战场** — 全球没人占的蓝海词，XIHE可以抢先定义
4. **第四层（医疗采购）是分水岭** — 二类证+NIQS+SGS+手术台垫=几乎无竞品能同时提供
5. **第五层（CEO问题）是整个旅程的终点** — CEO问完差异化问题后，要么联系你，要么不
