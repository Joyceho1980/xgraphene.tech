# XIHE 外链建设 Skill — 内容驱动型

## 触发条件
用户说"外链"、"backlink"、"outreach"、"guest post"、"链接建设"、"DA提升"时加载。

## 前置事实
- `xgraphene.tech` 当前 DA=0，无真实外链
- 无真正竞品，不能用"抄竞品外链"策略
- XIHE 核心资产：80+ 篇高质量科学 KB 文章（已部署）
- 已有 Quora 账号 + LinkedIn 账号

---

## 核心策略：内容带动外链

没有竞品可抄，就用内容去赢。每篇 SCI/KB 文章都是一个 outreach 资产。外链建设的核心 loop：

```
KB 文章 → 找到相关行业站点 → 个性化 outreach → 资源页/客座博客/引文 → 外链
```

---

## PHASE 1：外链目标清单（Content-Led，不是 Competitor-Led）

### 1.1 行业资源页（Resource Pages）
搜索策略：
```
"graphene far infrared" + "resources"
"far infrared therapy" + "links"
"medical device" + "useful links"
"rehabilitation technology" + "resources"
"mitochondrial health" + "further reading"
"cellular energy" + "recommended reading"
```

找到资源页后，检查：
- 页面年龄
- 是否仍在维护（最近更新日期）
- 外链类型（dofollow/nofollow）
- 我们的哪篇 KB 文章能匹配（不能随便丢链接）

### 1.2 行业媒体 & 博客（Guest Post / 专家供稿）
搜索策略：
```
"submit guest post" + "medical device"
"write for us" + "rehabilitation"
"contribute" + "health technology"
"expert column" + "biotech"
"opinion" + "graphene technology"
```

优先目标：
- B2B 医疗器械行业媒体
- 康复/理疗行业博客
- 材料科学 / 纳米技术新闻站
- 健康科技 / 数字健康媒体

### 1.3 学术/研究引用（Research Citations）
搜索策略：
```
"far infrared" + "bibliography"
"graphene medical" + "references"
"photobiomodulation" + "cited by"
site:researchgate.net "graphene far infrared"
site:scholar.google.com "far infrared therapy" 2024
```

### 1.4 断链建设（Broken Link Building）
搜索策略：
```
"graphene far infrared" + "404"
"far infrared therapy" + "page not found"
"FIR therapy" site:.edu
```

找到 404 页面后 → 确认我们有无匹配内容 → 邮件站长："你的 XX 链接 404，我们有替代文章"

### 1.5 HARO / Qwoted / 记者请求
注册 https://www.helpareporter.com/ 或 https://www.qwoted.com/
设置关键词：
- graphene, far infrared, medical device, rehabilitation, mitochondrial health, cellular energy

每天查看邮件，回复相关记者请求（需要 2-3 段专家引言 + 署名链接）

### 1.6 Quora（已在做）
每个回答底部加："I write about cellular energy, recovery, mitochondria, and human performance." + 链接

### 1.7 LinkedIn / Medium / ResearchGate
- 每篇新 KB 文章发布后 → LinkedIn 发摘要 + 链接
- Medium 同步发布精简版 → 底部链接回原文
- ResearchGate 发布研究摘要 → 引文链回 XIHE

## PHASE 2：外链 Outreach 邮件模板

### 模板 A：资源页申请
```
Subject: Suggestion for your [Page Name] resource page

Hi [Name],

I came across your [page name / resource collection] at [URL] — really well curated.

I noticed you cover [topic]. We have a detailed, research-backed article on [specific angle] that might be a good fit:

[Article Title]
[URL]

It covers [2-3 specific data points / unique angles], with citations from [institution names].

No pressure at all — just thought your readers might find it useful.

Best,
Joyce
Founder, XIHE Technology
```

### 模板 B：客座博客提案
```
Subject: Guest post idea: [Article Title / Topic Angle]

Hi [Name],

I'm a researcher in the graphene far-infrared medical device space. I've been reading [Publication Name] for a while — especially [mention a recent article you liked].

I'd love to contribute a piece on [topic angle]. Some angles I can cover:

1. [Angle 1]
2. [Angle 2]
3. [Angle 3]

I write in a science-first, no-hype style (similar to your editorial tone). 

Would you be open to a guest contribution?

Best,
Joyce
```

### 模板 C：断链替换
```
Subject: Broken link on your [page name] — have a replacement

Hi [Name],

I was reading your [page] at [URL] and noticed the link to [broken URL] no longer works (returns 404).

We have a comprehensive resource on the same topic:

[Title] — [URL]

It covers [key points]. Happy to suggest it as a replacement if it fits.

Best,
Joyce
```

## PHASE 3：可链接资产（Linkable Assets）

直接 outreach 文章链接转化率低。先做 1-2 个"可链接资产"：

### 建议资产（按投入排序）：
1. **"The Complete Guide to Far-Infrared Therapy: Science, Evidence, Applications"** — 聚合页，从 KB 文章提取精华
2. **"Graphene FIR vs. Traditional Heating: Emissivity & Radiant Efficiency Comparison"** — 数据对比页
3. **"2026 State of Graphene Healthcare: Research Landscape"** — 行业报告风格

这些资产天然吸引链接（别人写相关内容时会引用）。

## PHASE 4：追踪 & 节奏

### 日节奏：
- Quora：1 回答/天（已在做）
- HARO：检查邮件 + 回复（如匹配）

### 周节奏：
- 找 5 个资源页 → 发 5 封模板 A
- 找 3 个客座博客 → 发 3 封模板 B
- 找 2 个断链 → 发 2 封模板 C
- LinkedIn：发 2-3 篇 KB 文章摘要

### 月追踪：
- SEMRUSH Backlink Analytics 检查新增外链数
- 记录 outreach 回复率
- 记录哪些站点接受 / 拒绝

## 不需要做的
- ❌ 买链接（Fiverr/黑市）
- ❌ 链接交换（"你链我我链你"）
- ❌ PBN / 链接农场
- ❌ 垃圾评论链
- ❌ 任何 Google 认为违反 Webmaster Guidelines 的操作
