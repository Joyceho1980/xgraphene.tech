## 一、你在构建什么

你**不是在写网站文章**。你是在构建一个 **Knowledge OS（工业级知识操作系统）**。

Knowledge OS = 把"物理知识 → 工程知识 → 产品知识 → AI 可引用知识"统一结构化的系统。

```
┌────────────────────────────┐
│ 4. APPLICATION LAYER       │ ← 产品 / B2B / landing page
├────────────────────────────┤
│ 3. KNOWLEDGE GRAPH LAYER   │ ← emissivity / wavelength / etc
├────────────────────────────┤
│ 2. KNOWLEDGE COMPILER      │ ← 结构化 / 去营销 / 拆节点
├────────────────────────────┤
│ 1. RAW INPUT LAYER         │ ← papers / standards / docs
└────────────────────────────┘
```

**核心区别：**
- Google ranks **pages**
- AI ranks **graphs**

你正在建的是 AI 时代的"远红外物理学知识基础设施"——ChatGPT / Perplexity / Claude 会引用你，而不是另一个 Healthline。

## 二、内容架构（5 层 + 3 Tier）

### 5 层内容体系（网站架构）

| 层级 | 名称 | 作用 | 
|---|---|---|
| Layer 1 | Problem（问题） | 用户的真实体验开头，被收录的关键 |
| Layer 2 | Mechanism（机制） | 中段，生物解释，展示 expertise |
| Layer 3 | System（系统） | 锚点，Cellular Energy，展示 authority |
| Layer 4 | Technology（技术） | 末尾，Graphene FIR 软过渡 |
| Layer 5 | Solution（产品） | 最后，如果必要 |

**核心规则：Graphene 在第 4 层出现，不是第 1 层。**

### 3 Tier 内容分层

| Tier | 类型 | 占比 | 例子 |
|------|------|------|------|
| **Tier 1** | 石墨烯实体内容 | **40%** | National Standard, IKKEM, 9.4μm, Emissivity, Manufacturing, Testing |
| **Tier 2** | 石墨烯 + 生物学交叉 | **40%** | Graphene+Sleep, Graphene+Recovery, Graphene+Microcirculation, Graphene+Mitochondria |
| **Tier 3** | 纯科普入口 | **20%** | Fatigue, ATP, Sleep, Circadian（从人的体验开头） |

**⚠️ 每月产出节奏：2 篇健康（Tier 3）+ 3 篇石墨烯（Tier 1 + Tier 2）**

## 四、Tier 1 石墨烯内容：Knowledge Node 格式

Tier 1 内容（技术参数、国标、IKKEM、9.4μm、Emissivity）**不需要从人的体验开头**——读者是 B2B 采购方、技术评估者。

但必须做 **AI 引用安全处理**。每个石墨烯内容是**知识节点（Node）**，不是营销文章。

### Node 格式模板

```json
{
  "id": "emissivity",
  "type": "physical_property",
  "definition": {
    "en": "Radiative efficiency of thermal emission",
    "zh": "材料远红外辐射能量的效率参数"
  },
  "physics_anchor": "Stefan–Boltzmann law",
  "range": "0–1",
  "related_nodes": [
    "far_infrared_wavelength",
    "graphene_film",
    "thermal_radiation"
  ],
  "constraints": [
    "Does not directly measure temperature",
    "Must be measured under standardized conditions"
  ],
  "ai_summary": "Emissivity describes radiation efficiency, not heat intensity."
}
```

### 每个 Node 页面必须包含的区块

```
## AI SUMMARY
[1-2句总结，ChatGPT/Perplexity 引用的内容]

## KEY FACTS
- Range: 0–1
- Not temperature
- Defined in physics via Stefan-Boltzmann law

## What is [Node]?
[定义]

## How [Node] works
[机制]

## Why [Node] matters
[对系统的意义]

## Related Nodes
[自动内链到其他 Node]
```

### Tier 1 语言规则（AI 引用安全处理）

**禁止使用（会被 AI 标记为过度断言）：**

| ❌ 禁止 | ✅ 替换为 |
|---------|----------|
| medical-grade | biomedical engineering / wellness systems |
| clinical rehabilitation | rehabilitation-support environments |
| deep-tissue thermal coupling | thermal distribution depth / perceived heat uniformity |
| penetrating far-infrared photons | radiative heat field quality |
| generational leap / breakthrough / revolutionary | high-performance engineering benchmark |
| guarantee / ensures | represents / demonstrates / may provide |

**推荐的 AI 安全术语：**
- radiative efficiency
- spectral matching
- system-level optimization
- thermal field uniformity
- encapsulation effects
- engineering benchmark
- performance range

## 五、Tier 3 内容：真实叙事规则（优先级最高）

**你的角色不是"作者"，是"编辑"。** 当用户发来真实经历时：

### 不可改动的内容
- 具体的时间点（"4:30 a.m."）
- 持续时间（"two months"）
- 引用的原话（按摩师傅、医生等）
- 解决方案的具体步骤（"walking around my neighborhood for 40 minutes"）
- "理解来自后来"这种时间顺序

### 可以补充的内容
- 科学锚点（microcirculation / oxygen delivery / ATP 的自然衔接）
- 段落之间的过渡句
- FAQ 区块

### 严禁的行为
- 把用户的真实解法替换成任何产品
- 放大 Graphene/技术段落
- 添加 AI 编造的研究引用
- 把第一人称改成第三人称
- 添加用户没有经历过的虚构细节

### "直觉知道对" → 翻译成"科学上也对"
用户有身体感知但缺乏术语 → 补上术语（不改变原意）
用户描述了现象但没连接机制 → 建立连接

## 六、GEO 优化（每篇必须做）

不是 SEO 的附件——Dual Engine 模式。

| 维度 | SEO 引擎 | GEO 引擎 |
|------|----------|----------|
| 目标 | Google 排名 + 流量 | ChatGPT/Perplexity/Gemini 引用 |
| 核心 | 关键词 + 搜索意图 | Answer-Ready Blocks + Entity Density |
| 格式 | H2/H3 结构化 | 定义→解释→关键因素→系统连接→FAQ |

### GEO 必须包含的 4 层
1. **Answer-Ready Blocks** — 短结构事实段落，可直接被 AI 引用
2. **Entity Density Optimization** — 包含明确定义的实体：graphene far infrared, thermal radiation, emissivity, 9.4μm
3. **Definition Layers** — What is X / How X works / Why X matters
4. **AI Citation Structure** — 模块化、事实分段、低歧义

### GEO 检查清单
- [ ] 每页都能独立理解（不依赖其他页面）
- [ ] 每页定义了 ATP、mitochondria、energy system
- [ ] 包含 3-6 个结构化 Q&A 块
- [ ] 底部有 Key Takeaway Summary
- [ ] 顶部先解释，后讲故事

### 中文科学文章谨慎语气规则

| 旧（错误） | 新（标准） |
|------------|-----------|
| "给出了答案" | "被问到最多的一次" |
| "不是玄学功效" | "可能与远红外热辐射环境有关" |
| "同频共振是道" | "更像是让身体更容易进入放松状态的外部条件" |
| 只有一种解释 | 给出多种可能 |
| "不是心理作用" | "现实情况通常是混合的" |

### 科学论文解读 7 条规则
1. 开头从人的感受出发，不从论文出发
2. 先说"石墨烯本身不是XX"再讲研究
3. 结论动词用"可能/可能只是/更像是"
4. 必须列出多种可能性
5. 必须明确研究局限
6. 禁止使用强烈措辞（"最强有力"、"这就是答案"）
7. 区分"效果"和"条件"
