# 飞书桥接 — 操作步骤

## 第一步：初始化（你操作一次即可）

打开你的终端（PowerShell 或 CMD），复制下面这行命令，回车：

```
lark-channel-bridge run
```

终端会弹出一个二维码。用你的**飞书管理员账号**扫码。

扫码后自动完成：
- 创建飞书机器人
- 注册权限
- 绑定到你的飞书 workspace
- 保存配置到本地

## 第二步：验证

扫码成功后，在飞书里找到刚创建的机器人，发条消息试试。

## 第三步：启动桥接服务（我来操作）

你初始化完成后告诉我，我在这边跑：

```
lark-channel-bridge start
```

服务就会持续运行，把飞书消息和 AGENT-COMMS 任务系统连起来。
