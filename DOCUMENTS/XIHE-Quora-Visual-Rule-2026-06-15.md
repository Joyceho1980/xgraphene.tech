# XIHE Quora Visual Rule

Date: 2026-06-15
Purpose: define when Quora answers should use images, what kind of images are acceptable, and when text-only is the better choice.

## Core Principle

Quora is a text-first platform.

The default answer format is:

- text only

An image should be added only when it makes the biological explanation easier to understand.

## Default Rule

Most Quora answers should have:

- no image

This is especially true for:

- sleep questions
- fatigue questions
- basic inflammation questions
- general recovery questions
- broad consumer questions

Reason:

In these cases, the explanation itself is the value. An image often adds friction instead of clarity.

## When An Image Is Worth Using

Use an image only if both conditions are true:

1. the image reduces explanation difficulty
2. the image looks scientific, clean, and non-promotional

If either condition fails:

- do not use an image

## Good Use Cases For Images

### Type 1: Mechanism Clarification

Use an image when the answer depends on understanding a transition or process.

Examples:

- M1 -> M2 macrophage polarization
- inflammation -> resolution
- mitochondrial ATP production overview
- energy regulation across systems

### Type 2: System Relationship Map

Use an image when the question connects multiple systems.

Examples:

- sleep + immune function + energy
- inflammation + recovery + metabolism
- stress + fatigue + biological regulation

### Type 3: Simple Scientific Comparison

Use an image when a clean side-by-side structure improves comprehension.

Examples:

- acute vs chronic inflammation
- M1 vs M2 orientation
- passive rest vs active biological recovery

## Do Not Use Images For These

- basic sleep answers
- basic tiredness answers
- simple “what is X” answers
- answers where the image is only decorative
- answers where the image is more marketing than explanation

## Approved Image Styles

### 1. Minimal Mechanism Diagram

Characteristics:

- simple flow
- limited labels
- clean spacing
- no visual clutter
- science-note feel

Best for:

- M1/M2
- inflammation resolution
- mitochondria / ATP overview

### 2. Knowledge Card

Characteristics:

- one concept only
- very limited text
- neutral scientific tone
- high contrast but quiet design

Best for:

- acute vs chronic inflammation
- recovery cycle concept
- energy regulation concept

### 3. System Map

Characteristics:

- a few connected nodes
- visually simple
- relationship-first, not detail-first

Best for:

- cross-system questions
- higher-level biological explanation

## Disallowed Image Types

Never use:

- product photos
- brand ads
- promotional posters
- busy infographics
- long text-heavy diagrams
- decorative stock photos
- emotional wellness imagery with no explanatory function
- screenshots of papers unless specifically necessary

## Text Density Rule

If an image is used:

- keep on-image text minimal
- do not turn the image into a paragraph
- the answer text must still stand on its own without the image

The image is support, not the answer.

## Brand Rule

Quora visuals should not look like advertisements.

So:

- no XIHE branding on most images
- no product pitch
- no website CTA on image
- no logo-heavy layout

The image should feel like:

- scientific clarification

Not:

- branded marketing collateral

## Visual Decision Ladder

Before adding an image, ask:

1. Is the answer understandable without an image?
   - if yes, default to text only
2. Does the image reduce confusion?
   - if no, skip it
3. Is the image clean and scientific?
   - if no, skip it
4. Would the image make the answer look promotional?
   - if yes, skip it

## Fast Rules By Question Type

| Question Type | Default Visual Rule |
|---|---|
| sleep / tired after sleep | no image |
| basic fatigue | no image |
| what is inflammation | no image |
| chronic inflammation mechanism | optional simple mechanism card |
| mitochondria / ATP | optional simple mechanism diagram |
| M1/M2 / macrophage | image recommended if clean |
| cross-system biology | optional system map |

## Operating Rule

If an answer is:

- high traffic
- broad audience
- basic explanation

Then:

- do not spend time on visuals

If an answer is:

- mechanism-heavy
- high-authority
- reusable later in website / LinkedIn science content

Then:

- a clean reusable visual may be worth creating

## Reuse Rule

The best Quora visuals should be reusable across:

- Quora
- LinkedIn science posts
- website evidence pages
- knowledge hub cards

So if a visual is created, prefer:

- evergreen mechanism visuals

Not:

- one-off decorative images

## One-Sentence Summary

Quora answers should be text-first by default; visuals should be used only when they make a biological mechanism substantially easier to understand.
