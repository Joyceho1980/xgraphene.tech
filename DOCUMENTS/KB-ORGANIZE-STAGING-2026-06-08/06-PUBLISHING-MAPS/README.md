# XIHE Publishing Maps

Date created: 2026-06-08
Purpose: Connect KB sources to website pages, hubs, Quick Answers, FAQ, evidence, and internal links.

## Why This Folder Exists

The website should not be updated from scattered notes.

Every page should have a publishing record that says:

1. What question the page answers.
2. Which hub it belongs to.
3. Which KB concept files support it.
4. Which evidence sources support it.
5. What claim language is approved.
6. What the page must not claim.
7. Which internal links it needs.
8. Whether Quick Answer, FAQ, and schema are ready.

## Files

| File | Purpose |
|---|---|
| `KB-to-Website-Map.csv` | Master page map |
| `Article-Publishing-Record-Template.md` | Template for individual article records |

## Status Labels

| Status | Meaning |
|---|---|
| Idea | Topic exists but not sourced |
| Sourced | Concept and evidence sources identified |
| Draft | Article draft exists |
| Review | Needs evidence and claim review |
| Approved | Ready for website production |
| Published | Live on website |
| Refresh | Published but needs update |

## Priority Labels

| Priority | Meaning |
|---|---|
| P0 | Foundation page or high-risk governance page |
| P1 | High authority and high internal-link value |
| P2 | Important expansion page |
| P3 | Later editorial or outreach page |
