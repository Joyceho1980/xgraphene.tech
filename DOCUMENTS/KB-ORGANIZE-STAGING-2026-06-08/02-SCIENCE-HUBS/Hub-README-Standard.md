# Hub README Standard

Date created: 2026-06-08
Purpose: Standard structure for every XIHE Science Hub.

Use this template when upgrading hub README files in `02-SCIENCE-HUBS`.

## Hub Completion Checklist

- [ ] Hub thesis complete.
- [ ] Quick Answer complete.
- [ ] At least 5 human questions listed.
- [ ] Evidence map complete.
- [ ] At least 3 approved claims identified.
- [ ] At least 1 story hook identified if appropriate.
- [ ] Parent and child website URLs mapped.
- [ ] Internal links in and out listed.
- [ ] FAQ opportunities listed.
- [ ] Compliance boundaries written.
