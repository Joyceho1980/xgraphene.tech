## Folder Rules

### `02-SCIENCE/00-CELLULAR-SYSTEM`

Owns the neutral cellular biology foundation.

Use it to explain cells, ATP, mitochondria, microcirculation, redox biology, inflammation, recovery, sleep, metabolism, and aging before introducing graphene or FIR.

Graphene FIR should be a later technology bridge, not the starting point of these pages.

### `00-KB-SYSTEM`

Owns the method.

Use it for rules, templates, indexes, and operating protocols.

### `99-INBOX`

Owns unfinished inputs.

When the user shares an article, paper, story, or idea, save it here first unless the target folder is obvious and already has a record.

### `02-SCIENCE`

Owns scientific truth.

Do not use `02-JOURNAL` or `01-BRAND` as scientific evidence unless they link back to actual sources.

### `04-SEO-KEYWORDS`

Owns public claim language.

If a claim is not in this folder or a publishing record, treat it as unapproved.

### `06-PUBLISHING-MAPS`

Owns the bridge to website execution.

If we update the website, this folder should explain why and how.

## Do Not Create

Avoid creating random folders such as:

- `misc`
- `new`
- `drafts2`
- `final-final`
- `temp`

Use `99-INBOX` for raw material and templates for processed material.
