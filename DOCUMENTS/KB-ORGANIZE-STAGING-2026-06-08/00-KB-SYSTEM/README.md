# XIHE KB System

Status: Active
Created: 2026-06-08
Purpose: Operating system for the growable XIHE English Knowledge Base.

## What This Is

This is the control layer for a growable, markdown-first, AI-readable knowledge base.

The design is inspired by the simplest useful knowledge systems:

1. Source notes stay close to the original evidence.
2. Atomic concept notes explain one idea at a time.
3. Evergreen synthesis notes connect concepts across domains.
4. Claim cards control what can be said publicly.
5. Story bridges preserve human writing without turning story into evidence.
6. Publishing records convert the KB into website pages.
7. MOCs, or maps of content, make the whole system navigable.

## Permanent Rule

The KB is the source of truth.

The website is the published layer.

Social, outreach, decks, and articles are derivative outputs.

## Operating Loop

```text
Inbox
  -> Source Note
  -> Concept Note
  -> Evidence / Claim Card
  -> Story Bridge if useful
  -> Publishing Record
  -> Website Page
  -> Audit and Update
```

## Non-Destructive Policy

Do not mass-move old files until a source map exists.

Use indexes and templates first.

When files are eventually moved, leave redirect notes or update MOCs so no context is lost.
