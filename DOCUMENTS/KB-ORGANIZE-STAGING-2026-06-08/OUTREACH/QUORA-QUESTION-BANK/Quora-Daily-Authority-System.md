# Quora Daily Authority System

Status: Active
Created: 2026-06-08
Purpose: Use Quora questions to build XIHE's knowledge authority without turning answers into link spam.

## Core Position

Daily Quora answering is useful.

But the goal is not direct backlink ranking power.

The goal is:

1. Discover real human questions.
2. Build public expert presence.
3. Test which explanations people understand.
4. Turn repeated questions into article titles.
5. Feed the XIHE KB and website roadmap.
6. Create referral paths only when genuinely helpful.

## SEO Reality

Quora should not be treated as a simple backlink machine.

Quora's own answer policy says the gist of an answer should be understandable without forcing the reader to leave Quora.

Google recommends marking user-generated content links with `rel="ugc"`, and describes `nofollow` as a way to avoid implying endorsement or passing ranking credit. Google also treats these link attributes as signals or hints rather than a guaranteed ranking shortcut.

Therefore:

Quora can support SEO indirectly through visibility, referrals, entity building, and content intelligence.

It should not be used as spammy link-building.

## Daily Workflow

### Step 1: Pick One Question

Choose a question that is:

1. Human-worded.
2. Evergreen.
3. Connected to a XIHE hub.
4. Answerable from the KB.
5. Safe to answer without medical claims.

### Step 2: Save The Question

Add it to:

`Quora-Question-Bank.csv`

If it is high-value, create a full record in:

`Records/`

### Step 3: Map To KB

Every answer must map to:

1. Parent hub.
2. Primary concept note.
3. Supporting concept notes.
4. Evidence boundary.
5. Forbidden claims.

### Step 4: Draft The Answer

Answer structure:

1. Direct answer.
2. Human explanation.
3. Mechanism.
4. Nuance / tradeoff.
5. Optional further reading.

### Step 5: Link Carefully

Do not link in every answer.

Use links only when:

1. The answer already provides value.
2. The link is directly relevant.
3. The linked page is educational.
4. The answer does not sound promotional.

Recommended link ratio:

| Answer Type | Link Use |
|---|---|
| Pure definition | Usually no link |
| Deep explainer | Optional link |
| Evidence question | Link to research or hub if useful |
| Product-adjacent question | Usually no product link |
| High-performing answer | Add link only after answer is strong |

## 40-Question Cluster Strategy

If there are 40 related questions, do not answer all randomly.

Organize them into a cluster:

| Cluster | Example |
|---|---|
| Core definition | What are mitochondria? |
| Energy mechanism | How do mitochondria make ATP? |
| Fatigue connection | Why do muscles get tired? |
| Muscle types | Why do some muscles resist fatigue? |
| Recovery | Why does recovery take time? |
| Aging | Why does endurance change with age? |
| Evidence | What does research say? |
| Technology bridge | Can physical modalities affect cellular energy? |

## 40-Day Cadence

Recommended rhythm:

| Day Type | Answer Type |
|---|---|
| Day 1 | Core definition |
| Day 2 | Human fatigue question |
| Day 3 | Mechanism |
| Day 4 | Comparison |
| Day 5 | Story-led explanation |
| Day 6 | Evidence / limitation answer |
| Day 7 | Rest, review, and update KB |

Repeat weekly.

This prevents the account from sounding mechanical.

## Best Answer Style

Write like a thoughtful scientist explaining to a curious person.

Not like:

- marketer
- product seller
- keyword writer
- AI encyclopedia

Use phrases such as:

- "The short answer is..."
- "The deeper answer is tradeoff."
- "This is a useful intuition, but..."
- "I would separate the biology from product claims."
- "Evidence strength depends on the study type."

## Promotion Rule

After answering, decide:

| Result | Action |
|---|---|
| Weak question | Archive |
| Useful answer only | Keep in Quora bank |
| Strong FAQ | Add to future page FAQ |
| Strong article title | Create publishing record |
| Repeated topic | Build KB concept pack |

## Success Metrics

Track monthly:

1. Questions captured.
2. Answers posted.
3. Questions promoted to article title.
4. Questions promoted to FAQ.
5. Referral visits from Quora.
6. New website articles inspired by Quora.
7. Which answers get comments/upvotes.
8. Which explanations people understand best.

## Important Rule

Never answer from memory if the topic is scientific.

Answer from the KB.

If the KB does not yet support the answer, create a KB gap note first.
