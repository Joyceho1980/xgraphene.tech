# Quora Answer Template

Status: Active template
Created: 2026-06-08

## Answer Structure

```markdown
[Direct answer in 1-3 sentences.]

[Simple explanation in human language.]

[Mechanism or concept, if useful.]

[Nuance or limitation.]

[Optional further reading line.]
```

## Recommended Tone

Use:

- Clear
- Calm
- Educational
- Human
- Non-promotional
- Scientifically cautious

Avoid:

- Sales language
- Product promotion
- Overclaiming
- Excessive jargon
- Medical advice
- Keyword stuffing

## Template

```markdown
Short answer: [direct answer].

[Explain the concept simply.]

The key idea is [core concept from KB].

For example, [human analogy or everyday example].

One important nuance: [limitation / what this does not mean].

If you want to go deeper, look up: [neutral concept / optional XIHE knowledge hub link if genuinely useful].
```

## Compliance Footer Options

Use only when needed.

### Medical-adjacent question

```markdown
This is general biology education, not medical advice. If symptoms are persistent or severe, it is worth discussing them with a qualified healthcare professional.
```

### Evidence-limited question

```markdown
The mechanism is biologically plausible, but evidence strength depends on the study type. Human clinical evidence is different from animal or cellular research.
```

### Product-sensitive question

```markdown
I would separate the biology from product claims. The biology can be explained clearly, but whether a specific technology changes that biology requires direct evidence.
```

## Link Rule

Do not force links into every answer.

Use a link only when:

1. It genuinely helps the reader.
2. The linked page is educational.
3. The answer already gives value without the link.

Preferred link wording:

```markdown
For a longer explanation, I keep notes on cellular energy and related research here: [link]
```

Avoid:

```markdown
Buy / contact / check our products.
```
