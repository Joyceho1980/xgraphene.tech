# Cellular System Source Policy

Status: Active source policy
Created: 2026-06-08

## Purpose

The cellular system layer needs general biology sources, not only graphene FIR papers.

To build real authority, XIHE should cite:

1. Textbook-level biology concepts.
2. Review papers.
3. Mechanism papers.
4. Human physiology sources.
5. Graphene/FIR papers only when discussing the technology bridge.

## Source Types Needed

| Source Type | Use |
|---|---|
| Foundational biology textbooks or reputable references | Definitions and basic mechanisms |
| Review articles | Current scientific consensus and uncertainty |
| Mechanistic papers | Specific pathways |
| Clinical guidelines or consensus papers | Only when discussing broad health context |
| XIHE / graphene FIR evidence | Technology bridge only |

## Evidence Class Handling

Most foundational biology sources will be EC6 unless they report original experiments.

That is acceptable.

EC6 can support explanatory context. It cannot support product claims.

## Article Citation Rule

For a biology foundation article:

1. Use at least one general biology source or review.
2. Use graphene/FIR sources only in a separate bridge section if relevant.
3. Do not use graphene/FIR evidence to define basic cell biology.

## Priority Source Areas To Add

| Area | Source Need |
|---|---|
| ATP and energy metabolism | Basic bioenergetics references |
| Mitochondria | Review on mitochondrial function and dynamics |
| Microcirculation | Physiology review |
| Redox biology | ROS signaling and oxidative stress review |
| Inflammation | Innate immune response and resolution review |
| Sleep and recovery | Sleep physiology and glymphatic review |
| Cellular aging | Senescence, autophagy, mitochondrial aging reviews |

## Claim Boundary

General biology can explain why a system matters.

It cannot prove that XIHE changes that system.

For XIHE-specific claims, use claim cards and evidence governance.
