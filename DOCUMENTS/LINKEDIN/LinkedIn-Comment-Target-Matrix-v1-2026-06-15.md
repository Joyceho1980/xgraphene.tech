## XIHE LinkedIn Comment Target Matrix v1

Date: 2026-06-15

## Purpose

This file translates the LinkedIn comment system into a simple operating matrix.

It answers one practical question:

`What kind of posts should Joyce comment on, and what kind should she ignore?`

This is not a writing guide.

It is a targeting guide.

## The shortest possible rule

Comment on:

- people with real thinking
- posts with real signal
- threads where Joyce can add one useful layer

Do not comment on:

- noise
- PR for the sake of PR
- content where Joyce has nothing real to add

## Priority legend

- `Must Comment` = highest-value target when a strong draft exists
- `Can Comment` = optional, based on fit and time
- `Do Not Comment` = skip, follow, or ignore

## Must Comment

These are the best targets.

### 1. People with real viewpoints

Examples:

- founders talking about healthcare direction
- operators talking about patient workflow
- clinicians talking about recovery reality
- researchers talking about biological regulation

Why:

- people remember people
- strong people-posts create recognition loops
- this is the best place for Joyce to look like a thinker

### 2. Posts where one extra layer matters

This means the original post is good, but Joyce can add:

- a systems layer
- a recovery layer
- an energy-regulation layer
- a workflow implication

That is where the comment earns its place.

## Can Comment

These are conditional.

### 1. Strategic company posts

Only comment if the company post contains:

- a real patient experience point
- workflow logic
- rehab philosophy
- a partnership or expansion that implies strategic direction

If it is just an announcement, do not waste the comment.

### 2. CRM target posts with weak content

A CRM target does not automatically deserve a comment.

If the post is weak:

- follow
- monitor
- wait for a stronger thread

The relationship should not start with a low-value comment.

## Do Not Comment

This section matters as much as the rest.

### 1. Low-signal company broadcasting

Examples:

- "We're proud to announce..."
- "Happy Friday..."
- event photo carousel with no insight
- holiday greetings

Why not:

- no recognition upside
- easy to look performative

### 2. Empty motivational content

Examples:

- generic hustle quotes
- vague inspiration
- "consistency wins" without a deeper point

Why not:

- too easy to sound fake
- no place for Joyce to add real value

### 3. Threads where Joyce would be commenting only to be seen

This is the real danger zone.

If the comment exists only to show activity, skip it.

## CRM overlay rule

After using the matrix, apply the CRM overlay:

### Best-case target

- CRM target person
- good post
- clear way to add one layer

This is the ideal XIHE comment opportunity.

### Medium-value target

- CRM target company
- useful signal
- comment optional

### Low-value target

- non-target
- weak post
- no real fit

Ignore quickly.

## Daily operating rule

When time is limited, use this order:

1. CRM target person with real viewpoint
2. clinician or operator post with rehab / recovery depth
3. researcher post with mechanism depth
4. strategic company post only if unusually strong

Everything else is lower priority.

## Fast filter

Before commenting, ask:

1. Is this a person or just a broadcasting page?
2. Does this post contain a real judgment, not just information?
3. Can Joyce add one real layer?
4. Will this make Joyce look more like a thinker than a seller?

If the answer is `no` on any important part, do not comment.

## One-sentence summary

The best LinkedIn comment targets are not the loudest posts.

They are the posts where Joyce can place one intelligent layer inside a network that matters.
