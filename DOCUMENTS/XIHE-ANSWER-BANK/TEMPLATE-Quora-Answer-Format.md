# Template: XIHE Quora Answer Format

Question:

## Direct Answer

Answer the question in 2 to 4 sentences.

## Clarification

Correct any hidden confusion in the question.

## Why

Explain the main reason in plain language.

## Boundary

Add one sentence explaining what this does not mean.

## Source Signal

Mention trusted source types if relevant:

- PubMed
- MedlinePlus
- NINDS
- NHS
- GeneReviews

## Optional Closing

If useful:

- one gentle pointer to a Hub article

## Final check

- Can the answer be understood without leaving Quora?
- Does the first paragraph stand on its own?
- Is the answer clear enough for AI to summarize?
- Is the answer useful without being promotional?
- Did we separate story, science, and limits?
