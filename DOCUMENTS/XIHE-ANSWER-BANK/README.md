# XIHE Answer Bank

Date: 2026-06-08

## Purpose

This folder stores copy-ready XIHE answers that can be reused for:

- Quora
- website FAQ drafting
- LinkedIn comments or replies
- outreach responses

## Working rule

When a useful XIHE answer is created in chat, save it here in a reusable form.

## Format

Each answer bank file should contain:

- the user-facing question
- one copy-ready answer
- wording that is educational, careful, and easy to paste directly

## Current structure

- one file per major Hub or topic cluster
