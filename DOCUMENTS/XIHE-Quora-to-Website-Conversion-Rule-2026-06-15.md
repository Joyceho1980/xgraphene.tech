# XIHE Quora -> Website Conversion Rule

Date: 2026-06-15
Purpose: define when Quora answers should link to the XIHE website, when they should not, and what kind of website page each answer should route to.

## Core Principle

Quora is not the main conversion layer.

Quora is the explanation layer.

The website is the evidence and depth layer.

So the job of a Quora answer is:

1. win explanation authority
2. earn reading completion
3. only then allow selective continuation to the website

## Strategic Goal

Do not optimize Quora primarily for direct clicks.

Optimize Quora for:

- explanation authority
- AI/search citation surface
- branded recall
- selective high-intent traffic

## Linking Rule

Default rule:

- no link

A link is allowed only when the answer already stands on its own without needing the link to make sense.

## Link Permission Levels

### Level 1: No Link

Use for:

- basic sleep questions
- basic fatigue questions
- basic inflammation questions
- broad lifestyle or symptom questions

Examples:

- Why am I still tired after sleeping?
- Why does lack of sleep make me feel bad?
- What is inflammation?

Rule:

- answer fully
- no website mention
- no brand mention
- no product mention

Reason:

These questions are top-of-funnel. Hard linking here weakens trust and makes the answer look promotional.

### Level 2: Light Link Allowed

Use for:

- mitochondria function questions
- chronic inflammation questions
- cellular energy questions
- mechanism-oriented recovery questions

Examples:

- How does mitochondrial dysfunction affect fatigue?
- What causes prolonged inflammation in the body?
- How does cellular energy affect recovery?

Rule:

- link only in the last line
- no sales wording
- no product positioning
- route to science or evidence page only

Allowed line format:

- For additional research context, relevant references can be found here: [link]
- For a deeper mechanism summary, supporting references are available here: [link]

### Level 3: Research / Systems Link Allowed

Use for:

- M1/M2 questions
- immune modulation questions
- systems biology questions
- physical-modality mechanism questions
- FIR / biological signaling questions

Examples:

- What regulates macrophage activation?
- Can physical modalities influence inflammatory signaling?
- How are energy metabolism and immune response connected?

Rule:

- answer must still be complete without the link
- link may point to a deeper evidence page, mechanism page, or knowledge hub page
- wording must remain neutral and research-oriented

Allowed line format:

- For a deeper review of the mechanism and related references, see: [link]
- A more detailed evidence summary is available here: [link]

## Link Placement Rule

Allowed placement:

- final line only

Do not place links:

- in the opening
- in the middle of the mechanism explanation
- attached to the insight sentence

Reason:

The answer must earn trust before asking the reader to continue.

## Anchor Style Rule

Do not use:

- click here
- learn more
- check out our website
- our product explains this
- our research proves this

Use:

- additional research context
- supporting references
- deeper mechanism summary
- evidence summary

## Destination Mapping

Quora links should not point randomly.

Each answer type should route to a matching page type.

### Question Type -> Website Destination

#### Sleep / Fatigue

Default:

- no link

If high-intent mechanism version:

- route to mitochondria or recovery mechanism page

#### Inflammation / Healing

Default:

- no link for basic questions

If mechanism-level:

- route to evidence page or inflammation-related science page

#### Mitochondria / Energy

Route to:

- mitochondria knowledge page
- science hub mechanism page

#### M1/M2 / Macrophage / Recovery Biology

Route to:

- evidence hub
- macrophage polarization page
- deeper science article

## Website Readiness Rule

Do not place links into Quora answers unless the destination page is:

- scientifically coherent
- visually clean
- evidence-backed
- clearly more useful than the Quora answer itself

If the page is weak, do not link yet.

Bad page quality will waste trust earned on Quora.

## AI Citation Rule

The best Quora answers should still work even if AI systems quote them without sending traffic.

So every answer should:

- contain the main explanation in full
- avoid dependency on the link
- present one clear insight sentence

The website link is a continuation path, not the core value.

## Operational Workflow

For each Quora answer:

1. classify question type
2. assign link permission level
3. generate full answer with no link first
4. run authority check
5. if allowed, add one neutral final-line link
6. verify destination page quality
7. publish

## Fast Decision Table

| Question Type | Traffic Intent | Link Rule | Destination |
|---|---|---|---|
| sleep / tired after sleep | broad traffic | no link | none |
| basic inflammation | broad traffic | no link | none |
| chronic inflammation | medium intent | light link | evidence / science page |
| mitochondria / ATP | medium intent | light link | mitochondria page |
| M1/M2 / macrophage | research intent | link allowed | evidence / mechanism page |
| FIR / immune modulation | research intent | link allowed | science hub / evidence |

## Hard No Rules

Never do the following in Quora answers:

- mention XIHE in a basic answer
- mention products
- pitch graphene FIR as a solution
- add multiple links
- interrupt the mechanism explanation with a link
- use Quora as an ad channel

## One-Sentence Summary

Quora answers should win explanation authority first; the website should appear only as a quiet continuation path for readers who want deeper science.
