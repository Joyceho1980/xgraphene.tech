## 📋 使用说明

### 图片规格要求
- **尺寸**: 520 x 320 像素（宽 x 高）
- **格式**: JPG/PNG
- **文件大小**: < 200KB（优化后）
- **许可**: CC0或免费商用许可

### HTML中使用方式
```html
<img src="{图片URL}" alt="{描述文字}" class="card-img">
```

### SEO优化建议
1. **ALT属性**: 使用描述性文字，包含关键词
2. **文件命名**: 使用语义化名称（如 `afternoon-fatigue-office.jpg`）
3. **懒加载**: 可添加 `loading="lazy"` 属性
4. **响应式**: 已在CSS中设置适配

### 性能优化
1. 使用CDN加速（Unsplash自带CDN）
2. 考虑使用WebP格式（如支持）
3. 添加图片预加载关键图片
4. 使用适当的压缩参数
