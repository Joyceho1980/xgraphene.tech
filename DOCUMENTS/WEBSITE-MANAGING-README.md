## 四、内容层级与语言约束

这是最关键的规则。**两个层级是两种语言，不能混用。**

| | 🟢 Layer 2（输出层） | 🟠 Layer 4（调制层） |
|---|---|---|
| **目标** | 让用户理解自己的身体状态 | 解释一项研究观察到什么 |
| **解释方式** | 系统性解释（可以用比喻） | 实验观察（严格限定） |
| **允许说的** | "调频"、"节律"、"系统对齐" | "EEG测量到Alpha波提升2.3倍" |
| **禁止说的** | "7-14μm发射率0.98"（太技术） | "石墨烯可以治疗失眠"（越界） |
| **语气** | 体验 + 可理解机制 | 只讲研究，不扩展结论 |

### 🧠 一句话统一规则

- **Sleep Hub** 回答："这对睡眠意味着什么？"（允许：调频、系统、解释模型）
- **Graphene Hub** 回答："研究中观察到了什么？"（只允许：EEG measured increase、alpha/theta changes reported）
- **Product / Experience** 回答："用户可能感受到什么？"（只允许：some users report、individual variation）

## 八、写作规则汇编

### 8.1 核心原则

- 不要在文章开头解释概念。从人的感受出发。
- 三不：不过度解释 / 不过早确定 / 不用列表式堆机制
- 70% 句子 15 个字以内。一句一段。一个机制一个段落。

### 8.2 三步选型

1. **选节点** — 从 5 个 Core Narrative Nodes 中选主节点 + 次节点
2. **定类型** — 入口页（承接流量）/ 枢纽页（引导跨 Hub）/ 深度页（讲透机制）
3. **定声调** — System Thinker / Science Observer / Founder Philosopher

### 8.3 六层路径

```
Human Experience → System Mismatch → Cellular Explanation → System Interaction → Recovery Environment → Back to Copy
```

每一层至少一段，不允许跳过。

### 8.4 禁止用词

- cure, treat, heal, breakthrough, miracle, revolutionary, proven, guarantees, works for everyone
- "这意味着..."（删掉）
- 夸大因果（"石墨烯让人睡着" → 改为 "研究观察到脑电波变化"）
