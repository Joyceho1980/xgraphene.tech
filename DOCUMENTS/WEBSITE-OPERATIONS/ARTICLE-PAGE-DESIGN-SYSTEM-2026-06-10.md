# XIHE Article Page Design System

Date: 2026-06-10

## 1. Page Structure

### Hero Section

Purpose:

- grab attention
- set the article's core emotion or question

Elements:

- H1: concise and strong, expressing the article's core question or tension rather than direct medical jargon
- H2/H3: optional supporting line for emotion or story
- Hero image: optional human subject, scene, or symbolic visual
- Callout / overlay copy: optional short line that orients the reader

Recommended tone:

- human first
- emotionally clear
- editorial rather than infographic-heavy

### Breadcrumb / Navigation

Show the hub hierarchy clearly:

- Science -> Knowledge -> Mitochondria -> [Article Title]

## 2. Body Content Layout

### Introduction / Hook

- Use a human story, scenario, or problem framing
- Avoid leading with heavy medical jargon
- Keep it short and readable

### Key Concepts / Section Blocks

- Use one concept per block
- Give each block a clear title
- Add a supporting diagram, illustration, or visual only when it adds clarity
- Keep body text short: ideally 3-4 sentences per block

### Visual Guides

- Process topics: use arrows or step-based layouts
- Data topics: use simple charts, icons, or progress visuals
- Human/scenario topics: use photo or vector-style scene plus a short explanation

## 3. Sidebar / Floating Panel

Use for:

- Related Articles
- Quick Links
- Definitions such as ATP or mitochondrial dysfunction

Design:

- sticky on desktop when useful
- collapsible or stacked on mobile
- visible but not attention stealing

## 4. FAQ Section

- Use accordion-style interaction
- Keep each question short
- Give a direct answer first
- Link to the detailed section if needed
- Avoid long medical essays inside FAQ

## 5. Call-to-Action

Bottom-of-page CTA should point to:

- Hub
- Research Library

Optional product references:

- education-only
- no treatment claim
- no medical outcome claim

## 6. Typography and Color System

Typography:

- Headings: serif or semi-serif for trust and weight
- Body: sans-serif for readability
- Quotes / highlights: strong contrast, simple emphasis

Color palette:

- primary: calm technology blue
- secondary: light green or warm orange for emphasis
- highlights: light gray or brand background blocks

Links:

- brand color
- subtle hover motion

## 7. Imagery Guidelines

Hero:

- can rotate gender, age, and perspective
- can be human, back view, or atmospheric
- should match the article's hidden human question

Module images:

- simple
- clear
- informative
- consistent color language

Infographics:

- unified style
- minimal clutter
- easy to scan

## 8. Responsiveness

Mobile:

- hero image should resize cleanly
- text should remain readable
- sidebar should collapse into stacked cards or expandable blocks

Desktop:

- hero can be full-width or editorial two-column
- sidebar can stay visible if it helps navigation

## 9. Accessibility

- every hero and illustration needs meaningful alt text
- keep contrast high enough for reading
- keep font sizes readable
- accordions and CTAs should work with keyboard navigation

## 10. Article Hero Generation Workflow

Input:

- article text
- emotional context

Output:

- hero image
- optional overlay copy

Validation:

- place the image in `VISUAL-LIBRARY`
- check emotional fit
- check information fit
- check brand fit
