# Decision: Keyword Section Is A Priority Module

Date: 2026-06-11

## Decision

The `Keyword Section` is now considered a top-priority visual module for XIHE's outbound system.

It should not remain scattered across notes and prompt files.

It should become a dedicated workspace inside the visual prospecting system.

## Why This Matters

Keyword work feeds multiple systems at once:

- target-account discovery
- LinkedIn role discovery
- Google dorking and route discovery
- pain-point classification
- outreach-angle selection
- CRM tagging
- SEO and GEO planning

Because of this, the `Keyword Section` is not a support feature.

It is a central operating asset.

## Gemini Fit

Gemini is especially strong for keyword work because it can help:

- expand keyword variants
- cluster similar ideas
- separate commercial intent from clinical intent
- identify modality-adjacent language
- suggest pain-point groupings
- turn raw keywords into structured search packages

## Working Rule

Use:

- Gemini for keyword clustering and interpretation
- Google for real search execution and fact-finding
- CRM for persistence and reuse

## Conclusion

The `Keyword Section` should be built as a visual control center, not a static document list.
