# XIHE Quora Minimal Dashboard

Date: 2026-06-15
Status: active

## Start Here

If you only open one Quora file, open this one.

## Daily Rule

Answer 2 Quora questions every day.

This is the fixed execution rhythm.

Do not wait for perfect inspiration.

Use the question map, answer library, and KB to decide what to answer.

## Daily Mix

Default mix:

- 1 Tier 1 traffic question
- 1 Tier 2 or Tier 3 authority question

This keeps the system balanced between reach and credibility.

## Priority Order

1. Sleep and fatigue questions
2. Inflammation and recovery questions
3. Mitochondria and energy questions
4. Cross-system questions

## Answer Rule

Every answer should follow this structure:

1. Human framing
2. Biological explanation
3. System layer
4. Key insight
5. Optional light link

## Link Rule

Do not force links.

Use one link only when:

- the answer already stands on its own
- the link is educational
- the tone stays non-promotional

## Daily Workflow

1. Capture candidate questions
2. Score them
3. Pick 2
4. Draft from the KB
5. Post on Quora
6. Log result back into KB
