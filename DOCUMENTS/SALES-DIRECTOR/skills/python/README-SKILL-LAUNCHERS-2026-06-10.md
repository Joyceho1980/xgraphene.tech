# XIHE Sales Skill Launchers

Date: 2026-06-10

## Purpose

These Python files are lightweight launch helpers for XIHE sales skills.

They do not replace Codex skills.

They give a fast way to print the current operating references, starting steps, and required files for a workflow.

## Current Launcher

### launch_xihe_sales_skill.py

Use:

```powershell
python "D:\CODEX\LAUCH VERSION\DOCUMENTS\SALES-DIRECTOR\skills\python\launch_xihe_sales_skill.py"
```

What it does:

- prints the active XIHE sales skill
- lists the key reference documents
- shows the standard execution order
- reminds the operator of the core positioning rules

## Why This Exists

The Codex skill is the real reusable workflow.

This launcher is an operational shortcut so future sessions can quickly re-anchor around the right sales process.
