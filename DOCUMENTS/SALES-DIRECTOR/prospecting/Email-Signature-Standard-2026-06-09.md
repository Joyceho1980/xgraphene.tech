# Email Signature Standard

Date: 2026-06-09

## Default Signature

Use this signature for first-touch outbound emails unless a market-specific variation is needed.

```text
Best regards,

Joyce
XIHE Technology
Graphene Far-Infrared Recovery Systems
Email: Joyce@xgraphene.tech
Web: https://www.xgraphene.tech/
```

## Stronger Credibility Version

Use this version when the buyer is more technical or institutional.

```text
Best regards,

Joyce
XIHE Technology
Graphene Far-Infrared Recovery Systems
Backed by Jiageng Innovation Laboratory (55% shareholder)
Lead drafter of China's graphene electrothermal film industry standard
Email: Joyce@xgraphene.tech
Web: https://www.xgraphene.tech/
```

## Rule

- First-touch emails should use the default signature unless the body is already highly technical.
- Follow-up emails, technical one-pagers, and institutional outreach can use the stronger credibility version.
- Keep the signature clean. Do not overload it with awards, long slogans, or too many links.
