# XIHE Clinical Recovery Kits

Date: 2026-06-11

## Purpose

This document converts XIHE from a component story into a clinical workflow story.

The aim is to avoid selling:

- film
- heat
- graphene
- wavelength

in isolation.

Instead, XIHE should present stage-specific recovery kits that fit beside existing rehab workflows.

## Packaging Rule

Each kit must define:

1. clinical stage
2. visible workflow bottleneck
3. XIHE support role
4. buyer-facing value
5. proof required before aggressive claims are used

## Kit 1

### Internal working name

Acute Inflammation Management Kit

### External-facing commercial name

Acute Recovery Support Kit

### Target use stage

- early post-op
- acute flare
- high-sensitivity recovery window

### XIHE role

- non-invasive recovery support
- comfortable localized recovery environment
- supports a calmer post-treatment or post-procedure experience

### Buyer-facing value

- extends the recovery workflow beyond standard passive heat
- gives clinics a more differentiated post-op support layer
- may support premium recovery packaging when clinically appropriate

### Internal technical hypothesis

- microcirculation support
- local thermal consistency
- stage-specific recovery comfort advantage

### First-touch outreach-safe language

Use:

- post-op recovery support
- non-invasive recovery environment
- fits beside existing pain and rehab workflows

Avoid as a first-touch default:

- wavelength-specific certainty
- rapid edema-resolution claims
- opioid-reduction claims

## Kit 2

### Internal working name

Tissue Reconstruction Enhancement Kit

### External-facing commercial name

Functional Recovery Support Kit

### Target use stage

- week 4 to week 8 rebuild phase
- slower functional recovery phase
- return-to-training preparation

### XIHE role

- supports a more complete recovery workflow
- creates a repeatable recovery environment between therapy sessions
- can sit beside sports rehab and performance recovery programming

### Buyer-facing value

- addresses the stage where progress often feels slower
- supports premium recovery or cash-pay add-on design
- helps differentiate the clinic without replacing core therapy

### Internal technical hypothesis

- recovery plateau support
- deeper tissue comfort
- ongoing structured recovery support between formal sessions

### First-touch outreach-safe language

Use:

- functional recovery support
- recovery workflow extension
- patient-friendly, repeatable recovery environment

Avoid as a first-touch default:

- ATP-generation claims
- hard cell-level repair claims
- promises around shortening recovery time

## Kit 3

### Internal working name

OEM Integration Module

### External-facing commercial name

Integrated Recovery Environment Module

### Target use stage

- clinics with existing modality stacks
- PT, sports rehab, recovery suites, wellness recovery rooms
- accounts already using PEMF, compression, red light, or similar modalities

### XIHE role

- complements the existing stack
- broadens the recovery environment without forcing modality replacement
- supports premium suite design and workflow differentiation

### Buyer-facing value

- easier to discuss with modality-rich operators
- positions XIHE as complementary, not competitive
- creates a path toward OEM, room integration, or branded program design

### Internal technical hypothesis

- environment-level support layer
- modality adjacency
- better fit for operators that already sell a recovery stack

### First-touch outreach-safe language

Use:

- fits beside existing modalities
- integrated recovery workflow
- differentiated recovery room or recovery suite layer

Avoid as a first-touch default:

- upgrade claims that imply device equivalence
- direct superiority claims versus PEMF
- strong combined-therapy claims without evidence package

## Commercial Rule

For serious clinical accounts, the first conversation should not start with the kit names alone.

It should start with:

1. the workflow bottleneck
2. the visible clinical or service gap
3. the reason XIHE may fit beside what already exists
4. only then the best-fit kit

## Evidence Gate

Before stronger late-stage language is used, confirm which approved materials exist for:

- device classification
- clinical observation data
- approved before/after workflow examples
- any market-specific basis for `medical-grade` wording

## Working Conclusion

XIHE should sell:

- recovery support architecture
- stage-specific clinical kits
- integration modules for existing recovery programs

not just a material platform.
