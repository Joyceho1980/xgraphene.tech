# XIHE Product Naming Map

Date: 2026-06-12

## Purpose

This document standardizes XIHE's outward-facing product language across sales, CRM, keyword work, and website content.

## Core Names

- `Recovery Platform`
- `Recovery Environment`
- `Recovery Suite`
- `Energy Cabin`
- `Energy Wearables`
- `Recovery Modules`
- `Portable Recovery Add-ons`
- `Pet Recovery Cabin`
- `Pet Comfort Chamber`
- `Pet Wellness Pod`
- `Graphene Pet Recovery System`
- `Recovery Environment Brand`

## Naming Rule

Use the higher-level space or platform term first, then the concrete product or module.

Examples:

- `Recovery Platform` -> the full XIHE system
- `Recovery Environment` -> the space-level offering
- `Recovery Suite` -> a bundled room or premium space
- `Energy Cabin` -> a private enclosure or cabin experience
- `Energy Wearables` -> wearable recovery extensions
- `Recovery Modules` -> OEM or integration components
- `Portable Recovery Add-ons` -> entry-level or accessory products
- `Pet Recovery Cabin` -> pet-facing recovery enclosure concept
- `Pet Comfort Chamber` -> pet comfort-oriented enclosure concept
- `Pet Wellness Pod` -> compact premium pet wellness format
- `Graphene Pet Recovery System` -> the technical umbrella name for the pet line
- `Recovery Environment Brand` -> the brand umbrella for all recovery spaces, mats, nests, pods, cabins, and suites

## Brand Line

Use this as the top-level emotional statement when helpful:

- `Because Recovery Should Feel Like Home`

Use this as a contrast statement when needed:

- `Not a Therapy Device. A Recovery Environment.`

## Sales Rule

Lead with the experience or use case first.

Only then specify:

- FIR
- graphene
- modules
- wearables
- cabin structure

## Conclusion

These names should now be treated as the default outward vocabulary for XIHE.
